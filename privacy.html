プライバシーポリシー

制定日：2026年11月23日

AKUMU CHANNEL（以下「当チャンネル」）は、公式ホームページ（https://hk19830121-ai.github.io/、以下「本サイト」）における情報の取り扱いについて、以下のとおり定めます。

1. 取得する情報

本サイトでは、アクセス解析のために Google Analytics（GA4）を利用しています。Google Analytics は Cookie を使用して、閲覧したページ、滞在時間、ブラウザやデバイスの種類などのアクセス情報を収集します。これらの情報は匿名で収集されており、個人を特定するものではありません。

2. 利用目的

収集したアクセス情報は、本サイトの内容改善および運営の参考のためにのみ利用します。

3. 外部サービスへのリンク

本サイトには、Instagram、Threads、YouTube、note、X、Pinterest、Suno など外部サービスへのリンクが含まれます。リンク先のサービスにおける情報の取り扱いについては、各サービスのプライバシーポリシーをご確認ください。

4. APIの利用について

当チャンネルは、Pinterest API をはじめとする外部サービスの API を利用し、当チャンネル自身のアカウントにおける投稿データや分析情報（表示回数、保存数など）を取得して、運営の参考にすることがあります。取得した情報を第三者に販売または提供することはありません。

5. お問い合わせ

本ポリシーに関するお問い合わせは、akumu.channel.info@gmail.com までご連絡ください。

6. 改定

本ポリシーは、必要に応じて改定することがあります。改定した場合は、本ページにてお知らせします。
